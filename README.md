A single 137-character text message from a smart fridge to its owner at 3am: the owner came downstairs for water and stayed for a staring contest with the fridge light, and the fridge — a machine with a small voice, an opinion, and no shame about texting in the middle of the night — admits it blinked first, then lands the punchline that it doesn't even have eyes. It avoids the obvious milk, ice, and door-left-open angles for a fresher, lock-screen-sized joke about an appliance that has been awake all night.

## Run it

```sh
node main.ts
```
